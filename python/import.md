# Import файлов в python3  

## Где ищутся файлы?  

Python ищет модули по списку директорий из sys.path, в следующем порядке:  

- Директория запускаемого скрипта
- Пути из *PYTHONPATH*  
- Стандартная библиотека (/usr/lib/python3.X)  
- Установленные пакеты:  
   1. Активное виртуальное окружение (.../venv/lib/python3.X/site-packages)  
   2. Локальные пакеты пользователя (~/.local/lib/python3.X/site-packages)  
   3. Системные пакеты Ubuntu (/usr/local/lib/... и /usr/lib/python3/dist-packages)  

При использовании виртуального окружения пункты идущие до *Активное виртуальное окружение* также выполняются. После него соответственно не выполняются.  
Если запускать через python3 -m, то в первом пункте берется не директория где лежит скрипт, а директория откуда была запущена команда в терминале. Путь до скрипта в python3 -m указать возможности нет, поэтому пишется просто имя модуля и python ищет его по тому же списку, когда файл найден дальше импорты внутри этого файла заново ищутся по этому списку (условно получается, что мы два раза проходимся по списку, при поиске модуля и при импортах внутри него)
